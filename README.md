# 今日航线

一个把工作推进、等待跟进、生活事项和每日收尾放在同一页的离线优先应用。

在线入口：<https://yangxu-511.github.io/today-route/>

## 现在能做什么

- 快速记录事项，并放入“推进工作 / 等待与跟进 / 照顾生活”。
- 按今天、明天、以后整理；完成、移动或删除事项。
- 显示今日完成率，记录每日能量、成果和明日承接。
- 数据保存在当前浏览器；支持 JSON 备份导出和导入。
- 作为 PWA（可安装网页应用）在 Windows、Mac 和 iPhone 浏览器中使用；构建后支持离线打开。

## 本机运行

需要安装 Node.js 20.19+ 或 22.12+。

不熟悉终端时：

- Mac：双击 `启动今日航线-Mac.command`。
- Windows：双击 `启动今日航线-Windows.cmd`。
- 首次启动需要联网下载项目依赖；完成后打开 `http://localhost:4173`。

```bash
npm install
npm run dev
```

终端会显示地址。Mac 本机打开 `http://localhost:5173`；同一 Wi-Fi 下的 Windows 或 iPhone 可打开终端显示的 Network 地址。

## 安装到设备

- Mac / Windows（Chrome 或 Edge）：打开在线入口，点击地址栏右侧“安装”图标。
- iPhone（Safari）：打开在线入口，点击“分享”→“添加到主屏幕”。
- 换设备前：先点右上角“备份”；在新设备打开后点“导入”。首版没有云同步，不会自动把不同设备的数据合并。

## 验证

```bash
npm run test
npm run typecheck
npm run build
```

`npm run test:e2e` 是本项目的浏览器完整流程检查，需要先启动生产预览和一个开放 9223 调试端口的 Chrome；普通使用不需要运行它。

构建产物位于 `dist/`，可部署到任意 HTTPS 静态网站服务。

## 当前边界与下一阶段

- 当前数据只在设备本地，不接 CRM、企微或其他生产系统。
- 当前没有账号和云同步；跨设备依靠备份文件。
- iPhone 真机安装仍需在设备可连接时验证。
- 下一阶段应先验证连续 5 天实际使用，再决定是否增加可选的端到端加密同步、提醒和外部系统只读集成。
