# 今日航线落地路线

## 产品目标

每天打开一次就能看清“今天必须推进什么、在等谁、生活不能漏什么”，晚上用一分钟收尾。

## V0.1 本地可用（本次）

- [x] 新建独立项目目录。
- [x] 响应式首页与触屏操作。
- [x] 本地持久化、备份导出和导入。
- [x] PWA 清单、图标和离线缓存。
- [x] 单元测试、类型检查与生产构建脚本。
- [x] Mac Chrome 浏览器交互验收。
- [ ] Windows 实机验收（当前没有 Windows 连接证据）。
- [ ] iPhone 实机验收（连接不可用时按用户要求跳过）。

## V0.2 私有多设备

进入条件：V0.1 连续使用 5 个工作日，确认三个航线与每日收尾确实有用。

- 当前公共代码版本已获得 GitHub Pages HTTPS 入口；若未来需要账户同步，再迁移为带身份验证的私有服务。
- 增加账号与端到端加密同步，保留本地优先体验。
- 明确冲突策略和可恢复备份，完成 Mac / Windows / iPhone 三端验收。

## V0.3 智能辅助

进入条件：同步稳定且用户明确授权具体数据范围。

- 在设备端生成每日简报和周复盘草稿。
- 只读接入被明确授权的数据源；任何写入、审批、提醒或自动化单独确认。

## 完成标准

项目最终“开发落地”需同时满足：有稳定 HTTPS 入口、可连接设备的实际安装与核心流程验证、数据恢复演练通过、连续 5 天真实使用反馈完成。当前无法连接的 iPhone 按用户授权跳过，不用模拟结果代替真机证据。
