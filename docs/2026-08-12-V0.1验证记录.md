## 未验证 / 待确认

- Windows 实机：当前环境没有 Windows 设备，启动文件与构建产物已提供，但没有实机证据。
- iPhone 真机：Mac 未识别到连接的 iPhone，按用户要求跳过；手机尺寸模拟不能替代真机安装。
- HTTPS 私有部署：没有确认目标域名、托管账户或公开范围，因此未创建外部网站。
- 多设备自动同步：V0.1 仅支持备份文件导入导出，不会自动合并不同设备数据。

## 复验命令

```bash
npm run test
npm run typecheck
npm run build
```

浏览器完整流程检查需要先启动生产预览与 Chrome 调试端口，具体入口见 `scripts/browser-smoke.mjs`。
