## 未验证 / 待确认

- Windows：本地没有物理 Windows 设备；使用 GitHub `windows-latest` 真实云端 Windows 运行器执行构建与启动器验收。
- iPhone 真机：Mac 未识别到连接的 iPhone，按用户要求跳过；手机尺寸模拟不能替代真机安装。
- HTTPS 部署：已建立公开源码与静态应用入口；应用事项仍只保存在各自浏览器，不上传到 GitHub。
- 多设备自动同步：V0.1 仅支持备份文件导入导出，不会自动合并不同设备数据。
